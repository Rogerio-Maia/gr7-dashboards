# gr7-dashboards

Este repositório hospedava dashboards HTML gerados pelo mecanismo legado de publicação no GitHub Pages.

## Status

**Mecanismo legado descontinuado (DSEC01).** Todos os dashboards HTML históricos foram removidos da branch publicada em 05/09/2026 por decisão de segurança, por conterem dados de operação.

A geração de dashboards agora ocorre por infraestrutura própria, fora deste repositório.
